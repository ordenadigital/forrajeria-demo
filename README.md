# El Corralón — demo de tienda online

Demo estática y funcional para una forrajería y comercio de barrio.

## Publicar con GitHub Pages

1. Creá un repositorio nuevo en GitHub.
2. Subí todos los archivos y la carpeta `assets` a la raíz del repositorio.
3. En **Settings → Pages**, elegí **Deploy from a branch**.
4. Seleccioná la rama `main` y la carpeta `/ (root)`.
5. Guardá los cambios. GitHub mostrará la dirección pública cuando termine la publicación.

No requiere instalación, compilación ni servidor. El carrito se guarda en `localStorage` del navegador.
